# Archive

Not deployed. The Worker only serves `public/`.

`notion-media/` — original images from the Notion pages (170 files), copied from a local export.
File names are `<notion-page-id>-<index>-<original-name>`; the page ID matches the Notion URL suffix
(for example `34a8557f-…` is https://jefferyho.com/HIG-34a8557f73f44a98a93182959147364b).
Compressed card covers derived from these live in `public/v2/covers/`.
